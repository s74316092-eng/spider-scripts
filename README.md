# ScriptForge

Projeto inicial do site de comunidade de scripts.

## Rodar localmente
1. Instale Node.js.
2. Abra esta pasta no terminal.
3. Rode `npm install`.
4. Rode `npm start`.
5. Abra `http://localhost:3000`.

## Publicação online
Este projeto já tem um servidor Node/Express e endpoints para scripts, avaliações e downloads.
Para colocar na internet, é necessário escolher uma hospedagem e configurar o banco de dados/autenticação para produção.

O `data.json` serve apenas para protótipo local e não é adequado para uma comunidade real com muitos usuários.
